# AURION Documentation Map

## Objetivo
Este mapa ayuda a humanos y agentes IA a encontrar el documento correcto antes de actuar.

## Lectura mínima antes de programar
1. `00_GOVERNANCE/vision.md`
2. `00_GOVERNANCE/company-principles.md`
3. `02_PRODUCT/prd.md`
4. `03_ARCHITECTURE/architecture.md`
5. `08_DEVELOPMENT/agent.md`
6. `18_FRONTEND/frontend-architecture.md` si el cambio toca UI.
7. `19_BACKEND/hexagonal-clean-architecture-guide.md` si el cambio toca backend.
8. `20_DESIGN_SYSTEM/brand-strategy.md` si el cambio toca diseño.
9. `27_VOICE_IVR/voice-product-spec.md` si el cambio toca voz.
10. `29_HERMES_AGENT_WORKFORCE/hermes-agents-catalog.md` si el cambio toca agentes Hermes.

## Regla de oro
La IA debe buscar el documento específico, aplicar las reglas y actualizar la documentación si cambia una decisión.
