# 36_TEMPLATES

## Propósito
Plantillas reutilizables para PRD, ADR, API specs, historias, tests, incidentes, propuestas, implementación y skills.

## Uso por agentes IA
Antes de modificar cualquier parte relacionada con esta carpeta, el agente debe leer este README y el documento concreto aplicable.

## Documentos incluidos
- `prd-template.md`
- `adr-template.md`
- `api-spec-template.md`
- `user-story-template.md`
- `test-case-template.md`
- `incident-report-template.md`
- `sales-proposal-template.md`
- `client-implementation-template.md`
- `agent-skill-template.md`
- `meeting-notes-template.md`

## Regla
Si un documento no cubre una decisión necesaria, crear una propuesta y actualizar la documentación antes de implementar.
