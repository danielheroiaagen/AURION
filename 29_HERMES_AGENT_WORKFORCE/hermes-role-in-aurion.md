# Rol de Hermes Agent dentro de AURION

## Rol principal

Hermes Agent actúa como **capa de fuerza laboral autónoma asistida**. Es decir, ayuda a construir AURION, pero no sustituye la gobernanza humana.

## Posición en la arquitectura

```txt
Daniel / CEO
   ↓
Documentación estratégica
   ↓
Hermes Agent Workforce
   ↓
Agentes especializados
   ↓
Propuestas, código, tests, documentación, investigación
   ↓
Revisión humana + CI/CD + despliegue controlado
```

## Áreas donde Hermes sí trabaja

- Generación de documentación.
- Investigación técnica.
- Propuestas de arquitectura.
- Análisis de errores.
- Creación de tareas.
- Preparación de PRs.
- Creación de skills.
- Validación de requisitos.
- Auditoría de consistencia.

## Áreas donde Hermes no manda

- Producción.
- Seguridad.
- Datos sensibles.
- Facturación.
- Eliminación de datos.
- Cambios irreversibles.

## Principio CEO

Hermes puede acelerar la compañía, pero AURION debe tener frenos, volante y cinturón. Una IA rápida sin gobierno es un Ferrari bajando una montaña sin frenos.
