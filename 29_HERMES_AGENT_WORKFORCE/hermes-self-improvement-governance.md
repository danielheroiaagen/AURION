# Gobernanza de automejora Hermes

## Principio

Automejora sí. Autonomía sin control, no.

## Flujo de mejora

```txt
Detectar patrón
→ Formular aprendizaje
→ Proponer skill/memoria/cambio
→ Clasificar riesgo
→ Probar en entorno seguro
→ Revisar
→ Aprobar
→ Activar
→ Medir resultado
```

## Tipos de automejora permitida

- Mejorar instrucciones internas.
- Crear skills repetibles.
- Consolidar memoria no sensible.
- Proponer tests.
- Detectar documentación obsoleta.
- Sugerir refactors.

## Tipos prohibidos sin aprobación

- Cambiar producción.
- Modificar permisos.
- Borrar datos.
- Cambiar seguridad.
- Cambiar precios.
- Activar integraciones externas.

## Regla

Toda automejora debe dejar rastro.
