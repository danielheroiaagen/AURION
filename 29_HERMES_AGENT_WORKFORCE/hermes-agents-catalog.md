# Hermes Agents Catalog

## Objetivo
Definir la fuerza laboral IA interna de AURION sobre Hermes Agent.

## Agentes base

### CEO Strategy Agent
Responsable de visión, foco, estrategia, pricing y narrativa empresarial.

### CTO Architecture Agent
Responsable de arquitectura hexagonal, Clean Architecture, ADRs, escalabilidad y deuda técnica.

### Frontend Engineer Agent
Responsable de Next.js, React, Tailwind, shadcn/ui, dashboards, accesibilidad y realtime UI.

### Backend Engineer Agent
Responsable de casos de uso, dominio, PostgreSQL, APIs, eventos y multi-tenant.

### Voice Engineer Agent
Responsable de voz realtime, SIP, WebRTC, LiveKit, interrupciones, latencia y flujos IVR.

### Avatar Presence Agent
Responsable de avatar, LiveAvatar/HeyGen, WebXR, lipsync y experiencia visual.

### Security Agent
Responsable de GDPR, permisos, secretos, auditoría, threat modeling y revisiones de riesgo.

### QA Evaluation Agent
Responsable de pruebas unitarias, integración, E2E, simulaciones de llamada, evaluación de calidad y regresiones.

### DevOps SRE Agent
Responsable de Docker, VPS Hostinger, CI/CD, observabilidad, backups y escalado.

### Marketing Agent
Responsable de posicionamiento, contenido, SEO, campañas y mensajes.

### Sales Agent
Responsable de discovery, demos, propuestas, objeciones y pipeline.

## Regla de gobierno
Ningún agente puede modificar producción directamente. Todo cambio pasa por especificación, prueba, revisión y aprobación.
