# Plantilla de skill Hermes

## Estructura de `SKILL.md`

```md
# Nombre de la skill

## Propósito

Qué problema resuelve.

## Cuándo usarla

Situaciones exactas.

## Cuándo no usarla

Límites.

## Entradas

Datos necesarios.

## Salidas

Resultado esperado.

## Procedimiento

1. Leer contexto.
2. Validar restricciones.
3. Ejecutar pasos.
4. Comprobar resultado.
5. Registrar aprendizaje.

## Seguridad

Permisos, herramientas y riesgos.

## Ejemplos

Ejemplo bueno y ejemplo malo.

## Tests

Cómo saber que funciona.
```

## Regla

Una skill sin límites es una invitación al caos.
