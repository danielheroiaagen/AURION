# Checklists Hermes

## Checklist de instalación

- [ ] VPS preparado.
- [ ] Docker instalado.
- [ ] Usuario no-root.
- [ ] Firewall activo.
- [ ] Volumen persistente.
- [ ] Setup completado.
- [ ] Modelo configurado.
- [ ] Gateway cerrado o protegido.
- [ ] Backup configurado.
- [ ] Smoke test realizado.

## Checklist de skill

- [ ] Propósito claro.
- [ ] Entradas definidas.
- [ ] Salidas definidas.
- [ ] Límites definidos.
- [ ] Riesgos documentados.
- [ ] Tests incluidos.
- [ ] Revisión humana.

## Checklist de MCP

- [ ] Permisos mínimos.
- [ ] Sin secrets en docs.
- [ ] Read-only cuando sea posible.
- [ ] Logs activados.
- [ ] Prueba en staging.
- [ ] Aprobación de seguridad.
