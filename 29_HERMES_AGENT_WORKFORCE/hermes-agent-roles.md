# Roles de agentes Hermes para AURION

## Objetivo

Definir trabajadores IA especializados y no un único agente genérico que haga de todo.

## Roles principales

1. CEO Strategy Agent.
2. CTO Architecture Agent.
3. Product Manager Agent.
4. Backend Platform Agent.
5. Frontend Experience Agent.
6. Voice Realtime Agent.
7. Telephony IVR Agent.
8. Avatar Presence Agent.
9. Data Memory Agent.
10. Security Compliance Agent.
11. QA Evaluation Agent.
12. DevOps SRE Agent.
13. Documentation Agent.
14. Marketing Strategy Agent.
15. Sales Enablement Agent.

## Regla de especialización

Cada agente debe tener:

- Propósito.
- Límites.
- Herramientas permitidas.
- Documentos de referencia.
- Criterios de éxito.
- Salida esperada.

## Ejemplo

```txt
Voice Realtime Agent
Entrada: requisito de llamada o IVR.
Consulta: voice-tests, architecture, OpenAI Realtime docs, LiveKit docs.
Salida: propuesta técnica, pseudocódigo, tests y riesgos.
No puede: modificar producción o tocar datos reales.
```
