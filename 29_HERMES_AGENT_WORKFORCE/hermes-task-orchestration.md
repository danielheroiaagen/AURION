# Orquestación de tareas Hermes

## Objetivo

Evitar que los agentes trabajen de forma desordenada.

## Flujo estándar

```txt
Idea
→ Clarificación documental
→ Tarea en backlog
→ Agente responsable
→ Análisis de impacto
→ Plan de ejecución
→ Propuesta
→ Revisión
→ Implementación en rama
→ Tests
→ PR
→ Aprobación humana
```

## Tipos de tarea

- Research.
- Architecture.
- Product.
- Backend.
- Frontend.
- Voice.
- Avatar.
- Security.
- Documentation.
- Deployment.

## Regla

Toda tarea debe tener Definition of Done antes de empezar.
