# Hermes Agent — Overview estratégico

## Decisión ejecutiva

Hermes Agent será usado como **workforce interno de AURION**. Su función será coordinar trabajo técnico, documentación, revisión, investigación y mejora controlada del sistema.

## Qué aporta Hermes a AURION

- Memoria persistente para aprendizaje interno.
- Skills reutilizables para tareas repetibles.
- Integración con herramientas mediante MCP.
- Capacidad de operar desde VPS, no solo desde un portátil.
- Gateway para interacción por canales externos.
- Modelo de agente que mejora con la experiencia.

## Qué no debe hacer Hermes

- No debe ser el runtime principal de llamadas realtime.
- No debe ejecutar acciones contra producción sin approval.
- No debe mezclar memoria de desarrollo con datos sensibles de clientes.
- No debe tomar decisiones de arquitectura sin ADR.

## Relación con AURION

AURION tendrá dos mundos:

1. **Runtime de producto:** llamadas, voz, avatar, acciones empresariales y clientes.
2. **Runtime de trabajo interno:** Hermes Agent como equipo de agentes que construyen y mantienen AURION.

## Resultado esperado

Hermes debe convertir el desarrollo de AURION en una operación sistemática, no improvisada.
