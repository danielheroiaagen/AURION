# Code Review

## Objetivo

Evitar deuda técnica, fallos de seguridad y desviaciones arquitectónicas.

## Checklist

- ¿Respeta arquitectura hexagonal?
- ¿El dominio está limpio?
- ¿Hay tests?
- ¿Hay validación de inputs?
- ¿Respeta multi-tenant?
- ¿Registra auditoría si aplica?
- ¿Maneja errores?
- ¿Actualiza documentación?
- ¿Añade dependencias justificadas?

## Revisión IA

Un agente puede revisar, pero cambios críticos requieren humano.
