## Arquitectura base
- Hexagonal Architecture.
- Clean Architecture.
- PostgreSQL como base principal.
- Next.js/React/TypeScript/Tailwind/shadcn en frontend.
- Backend por casos de uso, puertos y adaptadores.
- Hermes Agent como fuerza laboral IA interna.
- Voz realtime con herramienta especializada y auditoría.
